# 描述（工作版）

> 原始需求见 `../原始系统提示词/描述.txt`；核心机制原稿见 `../原始系统提示词/核心.md`。
> 本文件是两者的结构化工作版，供实现时对照。

## 一、背景与目标

为实验**人脑与自然语言（多模态）模型的相关关系**，设计一套“在复杂环境中推理与训练”的方法。
目标是让模型**自己找数据、自己微调**，在回合制游戏中持续提升表现（用得分衡量）。

- 当前载体：`./model` 下的 **FastVLM-0.5B**（LLaVA-Qwen2 0.5B + MobileCLIP-L 视觉塔，视觉输入 1024px）
- 后续替换：**Qwen 系列大模型**
- 当前游戏：自建本地 **离线网页版 2048**
- 后续游戏：**宝可梦**（在接收端做兼容层，之后由用户直接向接收端 API 传图片，也支持文本）
- 约束：**模型本身不接任何联网模块**（否则会检索到最优解）

## 二、核心循环（每轮两次模型调用）

1. **输入**：整页原图（raw 图片）+ 短期记忆缓存（首轮附完整规则，之后简要提示以防遗忘）
2. **决策**：模型输出 `自我正思` + `self 操作`（单字操作）；可主动输出长期记忆读取指令
3. **执行**：操作脚本执行动作，产生**结果整页原图**
4. **反思**：模型判定好坏（最重要）并自我反思；给出它认为**应有的操作**；决定**是否微调**，若微调则算 loss 并立即反向传播
5. **记忆**：将以上全部内容作为输入，模型**全量覆盖**短期记忆缓存；输出中的长期记忆指令由系统执行
6. **下一轮**：本轮结果（raw 图片）+ 短期记忆缓存进入下一轮

约定：**一律喂图片，不喂矩阵 / 数值棋盘**；截图取整页原图；允许在图片范畴内做视觉增强。

## 三、记忆系统（仿人脑）

- **短期记忆 = 模型缓存（工作记忆）**：核心流程的一环，由模型自选内容，**全量覆盖**写入 `.json`，作为下一轮输入；首轮的完整规则也属于它。
- **长期记忆**：持久存储。
  - 读取：由模型**主动输出 read 指令**触发；系统每轮附带一份 **key 索引**帮助模型决策。
  - 检索：**允许模糊 / 相似匹配**。
  - 写入：模型输出统一结构，**schema 由我们强约束**。
- 遗忘：未来的优化方向。

## 四、训练机制（核心）

- 本质就是**模型微调**：监督目标 = 模型**实现操作的那些 token**。
- 反思阶段额外要求模型给出它认为**应该正确的操作**（单字），即“应有操作”。
- 取**错误操作**与**应有操作**的 embedding，**算相似度得到 loss**，再做正常梯度下降。
- 操作统一为**单个单词**（便于 embedding）。
- 可选：让模型自己决定**反向传播哪些操作 token**。
- **是否微调由模型自决**：简单经验进长期记忆；可抽象、可发展的内容（如抽象出的哲学）才触发微调。
- loss 幅度：与正常微调相当，可略大。
- 更新时机：模型决定微调后**立即**反传更新。
- 随机失活：前向启用 dropout；反向随机性**先跳过**（3 轮内再实现）。
- 硬件：当前 Linux / 无 GPU / 8 核 / 内存约 7GB，用 **LoRA + 量化、CPU 训练**；预留 GPU 全参训练接口。
- 所有具体超参写入**配置文件**，不硬编码。

## 五、接口与工程

- **一轮接口先定死**（`RoundInput` / `DecisionOutput` / `EnvironmentStep` / `ReflectionOutput`），以后换新框架只替换实现、不改接口。
- 代码用英文路径与英文文件名，参考 Java 工程：分层、接口抽象、关键注释、单行 ≤ 100 字符。
- 模型输出一律经**系统级强约束**为合法 JSON 后再执行。
